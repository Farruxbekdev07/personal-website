# Farruxbek Mirzakulov — Portfolio

A personal portfolio introducing Farruxbek Mirzakulov, an IT student at INHA University in Tashkent, and featuring his projects. The site uses only HTML, CSS, and JavaScript; no framework or build step is required.

## Project files

- `index.html` — page structure and content
- `styles.css` — colors, layout, animations, and responsive styling
- `script.js` — theme toggle, mobile menu, active navigation, typing and scroll reveal animations, and dynamic footer year

## Run locally

Open a terminal in the project folder and start a local server:

```powershell
python -m http.server 8000
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser.

## Website sections

- **About** — introduction, education, and links to Projects and Contact
- **Courses** — Object Oriented Programming 1, Introduction to IT, and Physics 1
- **Projects** — FreightFlow, Real-Time Messenger, and Student Grading Management System
- **Skills** — IT topics currently being explored
- **Contact** — placeholders for contact information

## Interactive features

- Light and dark themes; the selected theme is saved in the browser’s `localStorage`
- Responsive mobile navigation menu
- Navigation highlights the section currently in view
- Typing and scroll reveal animations that respect reduced motion preferences
- Footer year updates automatically

## Update contact information

An email address, GitHub profile, and LinkedIn profile were not provided, so the Contact section contains placeholders. Replace `your.email@example.com` and the professional links placeholder in `index.html` with your own details. The page does not include a nonfunctional contact form.
